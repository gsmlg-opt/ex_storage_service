NAME:
  mc idp ldap accesskey sts-revoke - revokes all STS accounts or specified types for the specified user

USAGE:
  mc idp ldap accesskey sts-revoke ALIAS USER [--all | --token-type TOKEN_TYPE]

  Exactly one of --all or --token-type must be specified.

FLAGS:
  --all                            revoke all STS accounts for the specified user
  --self                           revoke all STS accounts for the authenticated user
  --token-type value               specify the token type to revoke
  --config-dir value, -C value     path to configuration folder (default: "${HOME}/.mc") [$MC_CONFIG_DIR]
  --quiet, -q                      disable progress bar display [$MC_QUIET]
  --disable-pager, --dp            disable mc internal pager and print to raw stdout [$MC_DISABLE_PAGER]
  --no-color                       disable color theme [$MC_NO_COLOR]
  --json                           enable JSON lines formatted output [$MC_JSON]
  --debug                          enable debug output [$MC_DEBUG]
  --resolve value                  resolves HOST[:PORT] to an IP address. Example: minio.local:9000=10.10.75.1 [$MC_RESOLVE]
  --insecure                       disable SSL certificate verification [$MC_INSECURE]
  --limit-upload value             limits uploads to a maximum rate in KiB/s, MiB/s, GiB/s. (default: unlimited) [$MC_LIMIT_UPLOAD]
  --limit-download value           limits downloads to a maximum rate in KiB/s, MiB/s, GiB/s. (default: unlimited) [$MC_LIMIT_DOWNLOAD]
  --custom-header value, -H value  add custom HTTP header to the request. 'key:value' format.
  --help, -h                       show help
  
EXAMPLES:
  1. Revoke all STS accounts for LDAP user 'bobfisher'
   $ mc idp ldap accesskey sts-revoke myminio uid=bobfisher,ou=people,ou=hwengg,dc=min,dc=io --all

  2. Revoke all STS accounts for LDAP user 'bobfisher' (alt)
   $ mc idp ldap accesskey sts-revoke myminio bobfisher --all

  3. Revoke STS accounts of a token type 'app-1' for user 'user1'
   $ mc idp ldap accesskey sts-revoke myminio user1 --token-type app-1

  4. Revoke all STS accounts for the authenticated user (must be LDAP service account)
   $ mc idp ldap accesskey sts-revoke myminio --self

  5. Revoke STS accounts of a token type 'app-1' for the authenticated user (must be LDAP service account)
   $ mc idp ldap accesskey sts-revoke myminio --self --token-type app-1
