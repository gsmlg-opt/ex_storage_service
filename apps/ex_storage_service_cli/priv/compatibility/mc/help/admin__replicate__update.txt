NAME:
  mc admin replicate update - modify endpoint of site participating in site replication

USAGE:
  mc admin replicate update ALIAS --deployment-id [DEPLOYMENT-ID] --endpoint [NEW-ENDPOINT]

FLAGS:
  --config-dir value, -C value      path to configuration folder (default: "${HOME}/.mc") [$MC_CONFIG_DIR]
  --quiet, -q                       disable progress bar display [$MC_QUIET]
  --disable-pager, --dp             disable mc internal pager and print to raw stdout [$MC_DISABLE_PAGER]
  --no-color                        disable color theme [$MC_NO_COLOR]
  --json                            enable JSON lines formatted output [$MC_JSON]
  --debug                           enable debug output [$MC_DEBUG]
  --resolve value                   resolves HOST[:PORT] to an IP address. Example: minio.local:9000=10.10.75.1 [$MC_RESOLVE]
  --insecure                        disable SSL certificate verification [$MC_INSECURE]
  --limit-upload value              limits uploads to a maximum rate in KiB/s, MiB/s, GiB/s. (default: unlimited) [$MC_LIMIT_UPLOAD]
  --limit-download value            limits downloads to a maximum rate in KiB/s, MiB/s, GiB/s. (default: unlimited) [$MC_LIMIT_DOWNLOAD]
  --custom-header value, -H value   add custom HTTP header to the request. 'key:value' format.
  --deployment-id value             deployment id of the site, should be a unique value
  --endpoint value                  endpoint for the site
  --mode value                      change mode of replication for this target, valid values are ['sync', 'async'].
  --bucket-bandwidth value          Set default bandwidth limit for bucket in bytes per second (K,B,G,T for metric and Ki,Bi,Gi,Ti for IEC units)
  --disable-ilm-expiry-replication  disable ILM expiry rules replication
  --enable-ilm-expiry-replication   enable ILM expiry rules replication
  --help, -h                        show help
  

EXAMPLES:
  1. Edit a site endpoint participating in cluster-level replication:
     $ mc admin replicate update myminio --deployment-id c1758167-4426-454f-9aae-5c3dfdf6df64 --endpoint https://minio2:9000

  2. Set default bucket bandwidth limit for replication from myminio to the peer cluster with deployment-id c1758167-4426-454f-9aae-5c3dfdf6df64
     $ mc admin replicate update myminio --deployment-id c1758167-4426-454f-9aae-5c3dfdf6df64 --bucket-bandwidth "2G"

  3. Disable replication of ILM expiry in cluster-level replication:
     $ mc admin replicate update myminio --disable-ilm-expiry-replication

  4. Enable replication of ILM expiry in cluster-level replication:
     $ mc admin replicate update myminio --enable-ilm-expiry-replication
