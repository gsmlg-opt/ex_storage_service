NAME:
  mc idp openid accesskey list - list access key pairs for OpenID

USAGE:
  mc idp openid accesskey list [FLAGS] TARGET[:CFGNAME] [USER/ID...]

FLAGS:
  --users-only                     only list user DNs
  --temp-only                      only list temporary access keys
  --svcacc-only                    only list service account access keys
  --self                           list access keys for the authenticated user
  --all                            list all access keys for all OpenID users
  --all-configs                    list access keys for all OpenID configurations
  --config-dir value, -C value     path to configuration folder (default: "${HOME}/.mc") [$MC_CONFIG_DIR]
  --quiet, -q                      disable progress bar display [$MC_QUIET]
  --disable-pager, --dp            disable mc internal pager and print to raw stdout [$MC_DISABLE_PAGER]
  --no-color                       disable color theme [$MC_NO_COLOR]
  --json                           enable JSON lines formatted output [$MC_JSON]
  --debug                          enable debug output [$MC_DEBUG]
  --resolve value                  resolves HOST[:PORT] to an IP address. Example: minio.local:9000=10.10.75.1 [$MC_RESOLVE]
  --insecure                       disable SSL certificate verification [$MC_INSECURE]
  --limit-upload value             limits uploads to a maximum rate in KiB/s, MiB/s, GiB/s. (default: unlimited) [$MC_LIMIT_UPLOAD]
  --limit-download value           limits downloads to a maximum rate in KiB/s, MiB/s, GiB/s. (default: unlimited) [$MC_LIMIT_DOWNLOAD]
  --custom-header value, -H value  add custom HTTP header to the request. 'key:value' format.
  --help, -h                       show help
  
EXAMPLES:
  1. Get list of all OpenID users and associated access keys in local server (if admin)
    $ mc idp openid accesskey list local/

  2. Get list of OpenID users in local server (if admin)
    $ mc idp openid accesskey list local/ --users-only

  3. Get list of all users and associated temporary access keys in play server (if admin)
   $ mc idp openid accesskey list play/ --temp-only

  4. Get list of access keys associated with internal name 'openidinternalname'
     $ mc idp openid accesskey list play/ openidinternalname

  5. Get list of access keys associated with ID claim 'openidsub' (default claim is sub)
   $ mc idp openid accesskey list play/ openidsub

  7. Get authenticated user and associated access keys in local server (if not admin)
   $ mc idp openid accesskey list local/
