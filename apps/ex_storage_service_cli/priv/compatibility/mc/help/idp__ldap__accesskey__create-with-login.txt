NAME:
  mc idp ldap accesskey create-with-login - login using LDAP credentials to generate access key pair

USAGE:
  mc idp ldap accesskey create-with-login [FLAGS] URL

FLAGS:
  --ldap-username value            username to login as (prompt if empty)
  --ldap-password value            password for ldap-user (prompt if empty)
  --access-key value               set an access key for the account
  --secret-key value               set a secret key for the  account
  --policy value                   path to a JSON policy file
  --name value                     friendly name for the account
  --description value              description for the account
  --expiry-duration value          duration before the access key expires
  --expiry value                   expiry date for the access key
  --config-dir value, -C value     path to configuration folder (default: "${HOME}/.mc") [$MC_CONFIG_DIR]
  --quiet, -q                      disable progress bar display [$MC_QUIET]
  --disable-pager, --dp            disable mc internal pager and print to raw stdout [$MC_DISABLE_PAGER]
  --no-color                       disable color theme [$MC_NO_COLOR]
  --json                           enable JSON lines formatted output [$MC_JSON]
  --debug                          enable debug output [$MC_DEBUG]
  --resolve value                  resolves HOST[:PORT] to an IP address. Example: minio.local:9000=10.10.75.1 [$MC_RESOLVE]
  --insecure                       disable SSL certificate verification [$MC_INSECURE]
  --limit-upload value             limits uploads to a maximum rate in KiB/s, MiB/s, GiB/s. (default: unlimited) [$MC_LIMIT_UPLOAD]
  --limit-download value           limits downloads to a maximum rate in KiB/s, MiB/s, GiB/s. (default: unlimited) [$MC_LIMIT_DOWNLOAD]
  --custom-header value, -H value  add custom HTTP header to the request. 'key:value' format.
  --help, -h                       show help
  
EXAMPLES:
  1. Create a new access key pair for https://minio.example.com by logging in with LDAP credentials
     $ mc idp ldap accesskey create-with-login https://minio.example.com

  2. Create a new access key pair for http://localhost:9000 via login with custom access key and secret key 
     $ mc idp ldap accesskey create-with-login http://localhost:9000 --access-key myaccesskey --secret-key mysecretkey
