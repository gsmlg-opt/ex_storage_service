JMESPath evaluator and parser port
================================

Derived from the published Hex jmes 0.4.1 package.
https://hex.pm/packages/jmes/0.4.1
Package checksum: a16f10e87af9a1dfe829a072437d7dd89d46fc4f6c59aff936ef9ec8306f2db1

Modified for CLI-private namespaces, built-in JSON, string-key-only lookups,
correctness fixes, tagged expression references, and bounded execution.
The generated scanner uses OTP leex DFA rules, not backtracking runtime regex.
Token/AST names are fixed source atoms; identifier/function/map names are binaries.
