# Native mc compatibility gaps

Baseline: `minio/mc@77f82e18b5401a65958f1619df6ebb994634bd88`; checkout `9b8661e58107eddb24cb8f15495cee4ac979219a` plus current implementation diff. This source audit is separate from executable differential and provider acceptance.

Invocation-scoped config/pager/TLS/custom-header flags and aggregate upload/download limits now have scoped implementations; see native-global-options-decisions.md and native-rate-limits-decisions.md. Read/write socket inactivity deadlines now have scoped published HTTP 0.21.13 implementations; positive values must be exactly representable in whole milliseconds from 1 through 4,294,967,295, and zero disables the selected limit. The separate consumer ACK policy now uses published HTTP 0.21.13, with real paced-delivery and concurrent-isolation acceptance; see http-021-evaluation.md. The former 0.18 infinity gap (#123), #126 socket-inactivity gap and 0.21.11 network-await gap (#129) are historical/version-specific; they do not make the current deadline spellings absent. Unchecked rows track exact mc parity, including the explicit ESS differences in native-compatibility-dispositions.md; they are not all missing portable workflow implementations under M8. A registered native command with a matching name is an implemented mapping, not proven mc compatibility. Missing flags below compare primary pinned spellings with actual Registry options and native globals; aliases and similarly named flags do not establish equivalent types/defaults/effects. Implemented flag machinery retains scoped evidence; flags without tested effects remain open. No command inherits full compatibility from a matching spelling.

## Full-document alternatives

The following are useful native APIs, not replacements for missing pinned mc syntax: `ilm get|set|remove`, `event get|set|remove`, `replicate get|set|remove`, `encrypt get|set|remove`, `legalhold get|set|remove`, `retention get|set|remove`, `tag get|set|remove`, plus ACL/ownership/public-access/lock document families. Set accepts a complete modeled JSON structure. Unsupported Delete APIs fail explicitly rather than inventing removals.

Portable gaps include remaining flag/output/default contracts; notification nonportable default/mixed-event and flattened-output contracts; and the exact flag/argument/output contracts retained in the table. Portable lifecycle rule and deprecated aliases, encryption clear/info, bucket creation flags, governance conveniences, native resolve, bounded restore, replication conveniences, anonymous JSON/list/links and bounded find predicates now have focused implementations and tests; they do not establish complete mc parity. MinIO administration extensions retain their original out-of-scope classification and are not hidden in this portable gap list.

Scoped lifecycle rule, notification and tag convenience implementation/evidence is recorded in [management-convenience-decisions.md](management-convenience-decisions.md). Matching new command/flag spellings remain insufficient for complete mc verification.

M8 dispositions for every command/global row are recorded in [native-compatibility-dispositions.md](native-compatibility-dispositions.md). Missing native conveniences remain named; no model-level alternative is treated as their implementation.
