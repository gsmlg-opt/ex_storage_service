# Native compatibility dispositions

The native interface follows the ESS contract in design section 4.2. M8 accepts
working tested mappings or explicit scope/difference records; it does not promise
mc drop-in compatibility. The table assigns all 106 command/global rows in the
native checklist a disposition. Exact absent flag spellings remain in
[mc-native-gap-checklist.md](mc-native-gap-checklist.md); those missing
conveniences are not advertised as implemented. Their model-level alternatives
remain alternatives, not equivalent native grammar.

Existing decision reports and tests establish the implemented effects. Output,
default, safety and argument differences below are the documented ESS choices.
Per-member wire verification and live-provider evidence retain their independent
statuses. This disposition does not turn an unverified contract into a passing
reference comparison or remove any pinned AWS namespace requirement.
