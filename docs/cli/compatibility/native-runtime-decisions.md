# Native invocation resources

The CLI includes a small POSIX NIF compiled from source during installation or an escript build. It has no runtime compiler requirement or external Hex dependency. The source package includes the C source and Mix compiler; generated native binaries remain in the build tree. Escript assets carry OS, CPU, OTP-major and SHA256 checks. The loader extracts into an unpredictable private directory, loads the library, and removes its temporary files. Cross-platform/OTP escripts require a matching build.

The SIGINT/SIGTERM handler performs only lock-free atomic operations and a nonblocking self-pipe write. An atomic pending bitset retains both kinds when pipe writes coalesce. BEAM reads readiness through `enif_select`; the readiness tag remains `:ess_sigint` for both kinds and `drain/1` reports the pending subset. No BEAM API runs in a signal handler. Each invocation owns the resource. Explicit close or owner death restores both previous dispositions and releases descriptors. Pending handlers finish before descriptors can be reused. Linux kernel-private sigaction flags are excluded from the restoration test; user-visible flags and blocked signal masks are compared.

The same library provides `open_directory/2`, `read_directory/2`, and `close_directory/1` for bounded local traversal. A read returns at most 1024 binary entry names (128 by default), excludes dot entries, and never materializes a whole directory. The owner monitor and destructor release the directory descriptor. Opening rejects a final symlink unless explicitly requested; recursive traversal must still inspect entries and detect inode loops itself. Directory I/O runs on dirty I/O schedulers and has no interaction with signal state.

For terminal MFA, a separate monitored resource suppresses input echo and restores the complete previous termios settings on explicit close or owner death. Only one resource may change stdin echo at a time. OTP 28 `io:get_password` returns `enotsup` in noshell escripts, so the provider reads its line only after native echo suppression succeeds. Redirected/noninteractive stdin does not trigger a prompt.

Linux x86_64 / OTP 28 validation covers actual subprocess SIGINT/SIGTERM with exits 130/143, previous-handler restoration, owner-death cleanup, 100 repeated signal lifetimes with unchanged descriptor counts, bounded directory batches including non-UTF8 names, final-symlink behavior, retained-resource owner death, actual PTY MFA without echo and with terminal restoration, source-tree isolation, compiler cache corruption, embedded escript loading and temporary extraction cleanup. Darwin build flags exist; Darwin execution is unverified until the platform matrix runs.
